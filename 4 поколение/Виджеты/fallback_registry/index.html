    Реестр файлов для виджетов

    В setup.json укажите ID файла в поле изображения блока. Подробнее о setup.json.

    Найдите файл по ID или имени и скопируйте его ID из карточки. Превью уменьшены до 420 px. Ориентация, размеры и соотношение сторон указаны для исходного изображения.

    Данные реестра для агента в JSON. purpose — назначение изображения, category — ключ категории. Поле orientation: landscape — горизонтальное, portrait — вертикальное, square — квадратное. aspect_ratio — ширина, делённая на высоту; original_width и original_height — исходные размеры, width и height — размеры превью. Исключённые из публикации ID отсутствуют в JSON.
