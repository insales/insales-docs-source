    snippet.liquid

    Данный сниппет предназначен для написания html разметки. Осуществляется с помощью шаблонизатора liquidhub.

    Для виджета 4 поколения платформа оборачивает код сниппета так:

    <div
  class="layout widget-type_{handle}"
  style="--layout-wide-bg:true; --hide-mobile:false;"
  data-widget-drop-item-id="123456"
>
  <div class="layout__content">
    <!-- snippet.liquid -->
  </div>
</div>

    {handle} — значение handle из info.json. В style попадают не все настройки, а только те, которые платформа превращает в CSS-переменные. Подробнее — в snippet.scss. Значение любой настройки в Liquid доступно через widget_settings, даже если его нет в style.

    В примере ниже:

    • Получить значения настроек виджета из файла settings_form.json можно с помощью liquid-переменной widget_settings. Например, значение настройки ширины контента можно так: 
      {{ widget_settings.layout-wide-content }}
    • Если виджет блочный, то блоки можно получить из liquid-переменной data.blocks. Пример цикла для перебора блоков и получения значения свойства блока: 
      {% for block in data.blocks %}

{{ block.name }}

{% endfor %}
    • block.name - название, указанное в блоке. Набор полей зависит от шаблона блока.

    Другие примеры

    Если вам нужно узнать, какие переменные доступны на странице или какие есть свойства у объекта, то используйте help:

    {% help %} - выведет доступные переменные.

    {% help account %} - выведет список свойств объекта account

    Liquid-переменная widget_messages содержит переводы текстов для разных языковых версий из файла messages.json
