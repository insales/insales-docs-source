# Поиск

## Результаты

`GET /search.json?q=` возвращает массив товаров текущей страницы, без обёртки `status`. Параметры страницы: `page`, `page_size`, `order`.

<div class="api-example" markdown="block">
<div class="api-example__bar"><span class="api-verb api-verb--get">GET</span><code>/search.json?q=iphone&amp;page_size=1</code></div>
<table>
<thead>
<tr><th>Параметр</th><th>Описание</th></tr>
</thead>
<tbody>
<tr><td><code>q</code> <span class="api-req">обязательный</span><br>строка</td><td>Поисковая фраза. Пустая фраза или фраза без совпадений даёт пустой массив.</td></tr>
<tr><td><code>page</code> <span class="api-opt">необязательный</span><br>число</td><td>Номер страницы.</td></tr>
<tr><td><code>page_size</code> <span class="api-opt">необязательный</span><br>число</td><td>Сколько товаров вернуть. page_size=1 оставляет один товар.</td></tr>
<tr><td><code>order</code> <span class="api-opt">необязательный</span><br>строка</td><td>Порядок выдачи.</td></tr>
</tbody>
</table>

<div class="api-lang" data-lang="JavaScript" markdown="block">

```js
const params = new URLSearchParams({ q: "iphone", page_size: "1" });
const response = await fetch(`/search.json?${params}`, {
  credentials: "same-origin",
  headers: { Accept: "application/json" }
});
const products = await response.json();
```

## Подсказки

`GET /search_suggestions.json` нужен живому поиску в строке. Параметры: `query`, `locale`, `account_id`, `hide_items_out_of_stock`. `account_id` — id магазина, его печатает шаблон как `account.id`.

`data` в подсказке — id товара строкой. Переход из подсказки ведёт на `/product_by_id/{data}`.

<table>
<thead>
<tr><th>Параметр</th><th>Описание</th></tr>
</thead>
<tbody>
<tr><td><code>query</code> <span class="api-req">обязательный</span><br>строка</td><td>Фраза живого поиска.</td></tr>
<tr><td><code>locale</code> <span class="api-opt">необязательный</span><br>строка</td><td>Язык подсказок.</td></tr>
<tr><td><code>account_id</code> <span class="api-req">обязательный</span><br>число</td><td>id магазина, его печатает шаблон как account.id. Чужой id отвечает 400 и текстом Bad Request.</td></tr>
<tr><td><code>hide_items_out_of_stock</code> <span class="api-opt">необязательный</span><br>строка</td><td>Скрыть отсутствующие товары.</td></tr>
</tbody>
</table>

```js
const params = new URLSearchParams({

});

  credentials: "same-origin",
  headers: { Accept: "application/json" }
});
const data = await response.json();
```
