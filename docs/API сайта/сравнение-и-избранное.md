# Сравнение и избранное

Оба списка привязаны к сессии браузера, а у вошедшего покупателя ещё и к его профилю. Запросы без cookie сессии видят пустой список.

Актуальные адреса — `/front_api/compares.json` и `/front_api/favorites.json`. Старый `GET /compares.json` тоже отдаёт `{ "products": [] }`. `GET /favorites.json` отвечает HTML-страницей избранного, не JSON.

В карточках товаров те же поля, что у [списка товаров](товары.md).

## Сравнение

Добавление передаёт id товара. Повторный запрос с тем же id не создаёт вторую карточку.

<div class="api-example__bar"><span class="api-verb api-verb--post">POST</span><code>/front_api/compares.json</code></div>
<table>
<thead>
<tr><th>Параметр</th><th>Описание</th></tr>
</thead>
<tbody>
<tr><td><code>product[id]</code> <span class="api-req">обязательный</span><br>число</td><td>id товара. Повторный запрос с тем же id не создаёт вторую карточку.</td></tr>
</tbody>
</table>
<div class="api-example__grid" markdown="block">
<div class="api-example__pane api-example__pane--request" markdown="block">
<div class="api-lang" data-lang="JavaScript" markdown="block">

```js
const csrfToken = document.querySelector('meta[name="csrf-token"]').content;

const response = await fetch("/front_api/compares.json", {
  method: "POST",
  credentials: "same-origin",
  headers: {
    Accept: "application/json",
    "Content-Type": "application/json",
    "X-CSRF-Token": csrfToken
  },
  body: JSON.stringify({ product: { id: 761 } })
});
const data = await response.json();
```

</div>

```json
      "url": "/product/apple-iphone-16-128-gb",
      "available": true,
      "price_min": 84990.0
    }
  ]
}
```

`GET /front_api/compares.json` возвращает тот же список без поля `status`: `{ "products": [] }`, если сравнение пустое.

Очистка: `POST /front_api/compares/clear.json` с тем же заголовком CSRF. Ответ снова `{ "status": "ok", "products": [] }`.

Старый `POST /compares.json` с телом `product[id]` отвечает только `{ "status": "ok" }`, без списка товаров. Удаление — `POST /compares/:id.json` с `_method=delete`, ответ тот же короткий объект.

`GET /front_api/favorites.json` без товаров: `{ "products": [] }`.

`POST /front_api/favorites/:id.json` с `_method=delete` возвращает список без удалённого товара и `status: "ok"`.
