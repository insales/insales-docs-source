# Товары

Актуальный список товаров — `GET /front_api/products.json`. Старый `GET /products_by_id/:ids.json` отвечает тем же конвертом `{ "status": "ok", "products": [] }`.

За один запрос передают не больше ста id. Лишние id отбрасываются.

## Список по id товаров

Параметр `ids` — id через запятую. Параметр `with` перечисляет дополнительные блоки через запятую. Без него в товаре нет описания, картинок целиком, опций и свойств: базовый объект и так содержит цены, модификации и признаки наличия.

Допустимые значения `with`: `reviews_count_cached`, `reviews_average_rating_cached`, `first_image`, `images`, `characteristics`, `option_names`, `variants`, `short_description`, `description`, `product_field_values`, `bundle_info`, `canonical_url_collection`, `price_kinds`, `video_links`, `properties`, `accessories`, `accessory_values`.

Отдельные параметры картинок и опций: `images_limit`, `image_resizing_rules`, `video_links_details`, `accessories`, `accessory_values`.

<div class="api-lang" data-lang="JavaScript" markdown="block">

```js
const ids = [761];
const withFields = ["accessories", "variants", "option_names"];
const url = `/front_api/products.json?ids=${ids.join(",")}&with=${withFields.join(",")}`;

const response = await fetch(url, {
  credentials: "same-origin",
  headers: { Accept: "application/json" }
});
const data = await response.json();
```

У товара `price_min` и `price_max` — числа. В примере оба равны `84990.0`: это нижняя и верхняя цена его модификаций. Цена самой модификации лежит в `variants[].price` и приходит строкой: у «Чёрный» это `"84990.0"`.

У опции «Гравировка» `min_count` равен 0, `max_count` равен 1: значение можно не выбирать или выбрать одно. В `accessory_values` есть «Без гравировки» за `"0.0"` и «Имя на корпусе» за `"500.0"`.

`reviews_count_cached` — число отзывов товара, `reviews_average_rating_cached` — средняя оценка. Пока оценок нет, в обоих полях `null`. Тексты отзывов этот ответ не отдаёт, их читает метод из раздела [отзывы](отзывы.md).

## Список по id модификаций

Нужен, когда в корзине или в «недавно смотрели» лежат id модификаций, а не товаров. В ответе всё равно товары. Модификации, которых нет, пропускаются.

<div class="api-example__bar"><span class="api-verb api-verb--get">GET</span><code>/front_api/products_with_variant_ids.json?variant_ids=2176487200</code></div>

<tr><th>Параметр</th><th>Описание</th></tr>
</thead>
<tbody>
<tr><td><code>variant_ids</code> <span class="api-req">обязательный</span><br>строка</td><td>id модификаций через запятую. Отсутствующие пропускаются.</td></tr>
<tr><td><code>with</code> <span class="api-opt">необязательный</span><br>строка</td><td>Те же дополнительные блоки, что у списка по id товаров. Блок variants этот адрес добавляет сам.</td></tr>
</tbody>

## Старый список по id

`GET /products_by_id/761,562.json` отвечает `{ "status": "ok", "products": [] }`. Для новых шаблонов удобнее `/front_api/products.json`: у него есть `with` и выборка по модификациям.
