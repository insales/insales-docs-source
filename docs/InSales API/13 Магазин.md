# Магазин

Аккаунт и домены можно читать и менять, если у приложения есть право на настройки магазина.

Действия приложения описаны в [приложениях](14%20Приложения,%20выгрузки,%20задачи%20и%20диалоги.md#действия-приложения). Доставка и точки самовывоза описаны в [доставке](17%20Доставка.md). Единицы измерения товара — в [товарах](10%20Товары.md#единицы-измерения). Склады и валюты склада — в [складах](18%20Склады.md). Способы оплаты — в [оплате](19%20Способы%20оплаты.md).

Если нужного права нет, ответ `403`:

```json
{"status":"error","message":"Недостаточно прав для операции"}
```

Дополнительные поля заказа, клиента и адреса — в [заказах и клиентах](12%20Заказы%20и%20клиенты.md#дополнительное-поле).

## Аккаунт

`GET /admin/account.json` возвращает объект магазина, в котором авторизовано приложение. Отдельного метода списка аккаунтов нет.

В том же объекте есть флаги скидок `enable_cart_discounts`, `enable_client_discounts`, `enable_group_discounts`, `enable_order_discounts`, а также `hide_items_out_of_stock`, `contact_phone`, `sms_notification_phone`, `icq`, `registration_type_id`, `inviter_id`, `created_at`.

`stock_currency_exchange_rate` — курс валюты склада по умолчанию к валюте сайта. При одинаковой валюте курс равен `1.0`. Как задать валюту — в [складах](18%20Склады.md#валюты-склада).

Через `PUT /admin/account.json` можно изменить `next_order_number` и `client_cookies_whitelist`. Название, организация, город и остальные поля из ответа на чтение этим запросом не меняются.

API возвращает HTTP-статус `200` как при успешном сохранении, так и при ошибке проверки полей. Проверяйте тело ответа: при успехе оно содержит `{"status":"ok"}`.

`next_order_number` задаёт номер следующего заказа. Новое значение должно быть больше максимального номера существующего заказа.

`client_cookies_whitelist` определяет, какие cookie сохраняются в заказе при оформлении. Передайте регулярные выражения, по одному на строку.

## Домены

`GET /admin/domains.json` возвращает домены магазина, начиная с основного. Технический поддомен `*.insales.io` не включается. Если доменов нет, возвращается `[]`.

При создании домена API удаляет схему, путь и префикс `www.`. Например, `https://www.docs-api-shop.example/path` сохраняется как `docs-api-shop.example`. Поддомен третьего уровня, например `msk.docs-api-shop.example`, сохраняется целиком.

<div class="api-example" markdown="block">
<div class="api-example__bar"><span class="api-verb api-verb--post">POST</span><code>/admin/domains.json</code></div>
<table>
<thead>
<tr><th>Параметр</th><th>Описание</th></tr>
</thead>
<tbody>
<tr><td><code>domain[domain]</code> <span class="api-req">обязательный</span><br>строка</td><td>Имя домена. Схема, путь и www отбрасываются.</td></tr>
<tr><td><code>domain[main]</code> <span class="api-opt">необязательный</span><br>логический</td><td>Признак основного домена. При создании можно не передавать.</td></tr>
</tbody>
</table>
<div class="api-example__grid" markdown="block">
<div class="api-example__pane api-example__pane--request" markdown="block">

```http
POST /admin/domains.json
Authorization: Basic API_KEY:API_PASSWORD
Accept: application/json
Content-Type: application/json

{
  "domain": {
    "domain": "https://www.docs-api-shop.example/path"
  }
}
```

</div>
</div>
<div class="api-example__pane" markdown="block">
<span class="api-pane-label">Ответ · 201</span>

```json
{
  "id": 4310871,
  "domain": "docs-api-shop.example",
  "main": false,
  "created_at": "2026-10-21T22:21:32.000+03:00",
  "updated_at": "2026-10-21T22:21:32.000+03:00"
}
```

</div>
</div>
</div>

Первый добавленный домен не становится основным автоматически. Чтобы назначить его основным, отправьте `PUT /admin/domains/4310871.json` с `{"domain":{"main":true}}`. API вернёт `200` и `"main": true`. Пока домен не настроен, `main_host` аккаунта продолжает содержать технический адрес.

Повтор того же имени — `422`, тело `{"domain":["Вы уже добавили этот домен"]}`. Имя без точки — `422`, тело `{"domain":["Неверный формат имени домена","Неверный формат имени домена"]}`: сообщение приходит дважды. Имя с `insales.ru` — `422`, тело `{"domain":["Домен не должен содержать в себе слова insales или ekam"]}`.

`DELETE /admin/domains/:id.json` отвечает `200`, тело пустое.
