# Отзывы

`GET /admin/reviews.json` возвращает отзывы товаров через API бэк-офиса, по убыванию `id`. Для работы с отзывами со стороны покупателя используйте [API сайта](../API%20сайта/отзывы.md).

По умолчанию список содержит отзывы без отметки спама. С `spam=true` возвращается только спам. На странице по умолчанию 10 отзывов. Параметр `per_page` ограничен диапазоном от 10 до 250: значения за его пределами заменяются ближайшей границей. Заголовка `X-TOTAL-PAGES` нет.

Отдельного суточного лимита для отзывов нет. Действует [общий лимит запросов API](01%20readme.md#лимит-запросов).

Для создания отзыва передайте `author`, `email`, `content` и `product_id`. Некорректный адрес почты отклоняется со статусом `422` и телом `{"email":["имеет неверное значение"]}`. Для несуществующего товара API возвращает `422` и `{"product_id":["Указан несуществующий товар"]}`.

`rating` — целое от 1 до 5 или `null`. Ноль отвечает `{"rating":["может иметь лишь значение большее или равное 1"]}`.

Дробное число сохраняется без дробной части: `4.5` становится `4`.

Если поле `published` передано, InSales сохраняет его значение. Если поле не передано и в магазине включена модерация, отзыв сохраняется с `published: false`. Переданное значение `created_at` также сохраняется.

Чтобы добавить ответ магазина, измените отзыв, передав `manager_reply` и `replied_at`. Поле `replied_q` в ответе станет `true`. Чтобы привязать отзыв к другому товару, передайте существующий `product_id`: в ответе изменятся `product_id`, `title` и `url`.

Если у товара нет изображения, `first_image` содержит адреса заглушек `/images/no_image_*.jpg`. Передать изображение при создании отзыва нельзя: запрос с `image_attributes.src` или с `attachment` и `filename` возвращает `500`, отзыв не создаётся.
