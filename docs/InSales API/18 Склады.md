# Склады

В этой статье описаны склады магазина, остатки по складам и валюты складского учёта. Остаток хранится у варианта товара: работа с ним описана в разделе [«Остаток»](10%20Товары.md#остаток).

## Склады {#склады}

`GET /admin/warehouses.json` возвращает склады магазина. У исходного склада `array_index` равен `0`, а `status` — `ready`. Поле остатка `quantity_at_warehouseN` использует `array_index` в качестве `N`. Работа с одним складом и связь `quantity` с `quantity_at_warehouse0` описаны в разделе [«Остаток»](10%20Товары.md#остаток).

Чтобы создать склад, отправьте `POST /admin/warehouses.json` с `title` и `position`. API вернёт `200` и объект склада со статусом `creating`. Поле `array_index` получит следующий свободный индекс. Пока склад создаётся, в JSON варианта нет соответствующего поля `quantity_at_warehouseN`.

Когда `status` станет `ready`, поле остатка нового склада появится у варианта. При нескольких готовых складах `quantity` содержит сумму остатков. Остаток каждого склада возвращается строкой.

`PUT /admin/warehouses/:id.json` изменяет `title` и `position`, возвращая объект склада. Удаление выполняется асинхронно: `DELETE /admin/warehouses/:id.json` возвращает `202` с пустым телом. При следующем чтении склад имеет `status: deleting`.

## Валюты склада {#валюты-склада}

Валюты склада можно читать и менять, если у приложения есть право на настройки магазина.

`GET /admin/stock_currencies.json` возвращает массив валют склада. У рубля по умолчанию `exchange_rate` равен `1.0`.

Валюта создаётся по `code` из справочника валют платформы: `USD`, `EUR`, `RUR` и другие. Неизвестный код — `422`, тело `{"currency_code":["имеет неверное значение"],"currency":["Не заполнены обязательные поля"]}`. Повтор кода — `422`, тело `{"currency_id":["уже существует"]}`.

Чтобы использовать ручной курс, передайте `exchange_rate_use_cb: false` и обязательное в этом режиме поле `exchange_rate_manual`. Без ручного курса API вернёт `422` и `{"exchange_rate_manual":["Не заполнены обязательные поля"]}`.

Курс к валюте сайта рассчитывается как ручной курс, умноженный на `1 + exchange_rate_percent / 100`. Например, `90.5` с надбавкой `2` даёт `exchange_rate: "92.31"`. Поле `cb_rate` по-прежнему содержит курс ЦБ, но в этом режиме не участвует в расчёте. Поле `exchange_rate_round` возвращается как `true`, даже если передать `false`.

Чтобы назначить валюту склада по умолчанию, передайте `is_default: true`. У прежней валюты этот признак будет снят. Нельзя снять признак с текущей валюты по умолчанию, не назначив другую: API вернёт `422` и `{"is_default":["Установите другую валюту по умолчанию"]}`.

Удаление валюты склада через API не поддерживается. Запрос `DELETE /admin/stock_currencies/:id.json` возвращает `404` с HTML-страницей.
