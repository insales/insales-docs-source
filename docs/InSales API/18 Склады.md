# Склады

Склад хранит остаток товара. Валюта склада — валюта, в которой этот остаток учитывается. Остаток одного склада у варианта — в [товарах](10%20Товары.md#остаток).

## Склады {#склады}

`GET /admin/warehouses.json` отдаёт склады. У исходного склада магазина `array_index` равен `0`, `status` равен `ready`. Число `N` в поле остатка `quantity_at_warehouseN` — это `array_index`. Один склад и совпадение `quantity` с `quantity_at_warehouse0` разобраны в [остатке варианта](10%20Товары.md#остаток).

`POST /admin/warehouses.json` отвечает `200` и объектом склада. `status` сразу после создания — `creating`, `array_index` назначается следующим свободным. В запросе принимаются `title` и `position`. Пока статус `creating`, в JSON варианта нет поля `quantity_at_warehouseN` этого склада.

Когда статус становится `ready`, поле появляется. `quantity` варианта при нескольких готовых складах — сумма остатков. Остаток каждого склада в ответе — строка.

`PUT /admin/warehouses/:id.json` меняет `title` и `position` и отвечает объектом склада. `DELETE /admin/warehouses/:id.json` отвечает `202` с пустым телом. Следующий `GET` показывает `status` равным `deleting`.

## Валюты склада {#валюты-склада}

Валюты склада можно читать и менять, если у приложения есть право на настройки магазина.

`GET /admin/stock_currencies.json` — массив валют склада. `GET /admin/stock_currency.json` — валюта по умолчанию, в ней дополнительно есть `rate` (курс валюты к базе курсов). У рубля по умолчанию `rate` и `exchange_rate` равны `1.0`.

Страна продажи и валюта склада между собой не связаны. `GET /admin/account_countries.json` отдаёт страны магазина, например `{"id":1,"code":"RU","title":"Россия"}`. В валюте склада нет поля страны: соответствие задаётся у себя.

Валюта создаётся по `code` из справочника валют платформы: `USD`, `EUR`, `RUR` и другие. Неизвестный код — `422`, тело `{"currency_code":["имеет неверное значение"],"currency":["Не заполнены обязательные поля"]}`. Повтор кода — `422`, тело `{"currency_id":["уже существует"]}`.

`exchange_rate_use_cb: false` требует `exchange_rate_manual`. Без него — `422`, тело `{"exchange_rate_manual":["Не заполнены обязательные поля"]}`. Курс к валюте сайта равен ручному курсу, умноженному на `1 + exchange_rate_percent / 100`. Ручной курс `90.5` и процент `2` дают `exchange_rate` `"92.31"`. `cb_rate` при этом остаётся курсом ЦБ этой валюты и в расчёт магазина не входит. `exchange_rate_round` в ответе есть и остаётся `true`, если передать `false`.

`is_default: true` делает валюту валютой склада по умолчанию и снимает признак с прежней. Снять признак с текущей валюты по умолчанию, не назначив другую, отвечает `422`, тело `{"is_default":["Установите другую валюту по умолчанию"]}`. `DELETE /admin/stock_currencies/:id.json` отвечает `404` и HTML-страницей: удаления валюты склада в API нет.
